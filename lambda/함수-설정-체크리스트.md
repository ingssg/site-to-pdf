# Lambda 함수 설정 체크리스트 (Container Image 연결 후)

## ✅ 완료된 단계

- [x] Container Image 연결

## 📋 다음 단계

### 1. 환경 변수 설정

1. Lambda 콘솔 → `site-to-pdf-worker2` 함수 선택
2. **"구성"** 탭 → **"환경 변수"** 클릭
3. **"편집"** 클릭
4. 다음 3개 변수 추가:
   - **키**: `SUPABASE_URL` / **값**: Supabase 프로젝트 URL
   - **키**: `SUPABASE_SERVICE_ROLE_KEY` / **값**: Supabase Service Role Key
   - **키**: `OPENAI_API_KEY` / **값**: OpenAI API Key
5. **"저장"** 클릭

### 2. 메모리 및 타임아웃 설정

1. **"구성"** 탭 → **"일반 구성"** 클릭
2. **"편집"** 클릭
3. 다음 설정 변경:
   - **메모리**: `2048 MB` (2GB) - 슬라이더를 오른쪽으로 이동
   - **제한 시간**: `15분 0초` (900초) - 최대값
   - **에피소드 스토리지**: `2048 MB` (2GB) - 필요시 증가
4. **"저장"** 클릭

### 3. Function URL 확인/생성

1. **"구성"** 탭 → **"함수 URL"** 클릭
2. Function URL이 있는지 확인
3. **없으면**:
   - **"함수 URL 생성"** 클릭
   - **인증 유형**: `NONE` 선택
   - **CORS**: 필요시 설정 (기본값으로도 가능)
   - **"저장"** 클릭
4. 생성된 Function URL 복사 (예: `https://xxxxx.lambda-url.ap-northeast-2.on.aws/`)

### 4. Vercel 환경 변수 업데이트

1. Vercel 콘솔 접속
2. 프로젝트 선택 → **Settings** → **Environment Variables**
3. `LAMBDA_FUNCTION_URL` 찾기
4. **값을 새 Function URL로 업데이트**:
   - 기존: `https://[old-function].lambda-url...`
   - 새로: `https://[site-to-pdf-worker2].lambda-url...`
5. **"Save"** 클릭
6. **Vercel 재배포** (자동 또는 수동)

### 5. 테스트

#### Lambda 함수 직접 테스트

1. Lambda 콘솔 → **"테스트"** 탭
2. **"새 이벤트 생성"** 클릭
3. 이벤트 이름: `test-container`
4. 이벤트 JSON:
   ```json
   {
     "body": "{\"jobId\":\"test-123\"}"
   }
   ```
5. **"저장"** 클릭
6. **"테스트"** 버튼 클릭
7. 실행 결과 확인

#### 실제 웹사이트에서 테스트

1. Vercel 배포된 사이트 접속
2. 크롤링 시작
3. "작업 대기 중" → "크롤링 중" → "완료" 상태 변화 확인

### 6. CloudWatch Logs 확인

1. Lambda 콘솔 → **"모니터링"** 탭
2. **"CloudWatch에서 로그 보기"** 클릭
3. 최신 로그 스트림 확인
4. 에러가 있는지 확인:
   - `[Lambda] 워커 시작` - 정상
   - `[Lambda] 작업 시작` - 정상
   - `Cannot find module` - 에러 (의존성 문제)
   - `Executable doesn't exist` - 에러 (브라우저 문제)

## ⚠️ 문제 해결

### "작업 대기 중"에서 멈추는 경우

- Lambda 함수가 호출되지 않음
- Vercel 환경 변수 `LAMBDA_FUNCTION_URL` 확인
- Function URL이 올바른지 확인

### Lambda 함수 에러 발생

- CloudWatch Logs에서 에러 확인
- 환경 변수가 모두 설정되었는지 확인
- 메모리/타임아웃이 충분한지 확인

### 크롤링이 시작되지 않는 경우

- Supabase 연결 확인
- Lambda 함수가 Supabase에서 작업을 가져오는지 확인
- CloudWatch Logs에서 `[Lambda] 작업 시작` 로그 확인
