# Docker 이미지 재빌드 가이드

## 문제
Playwright Chromium 브라우저를 Lambda 환경에서 찾지 못하는 문제가 발생했습니다.

## 해결 방법
Dockerfile을 수정하여 브라우저 경로를 명시적으로 설정했습니다.

## 변경 사항
1. **Dockerfile**: `PLAYWRIGHT_BROWSERS_PATH` 환경 변수 추가
2. **crawler.js**: 브라우저 경로 자동 감지 로직 추가
3. **pdf.js**: 브라우저 경로 자동 감지 로직 추가

## 다음 단계

### 1. Docker 이미지 재빌드 및 푸시

```bash
cd lambda
./build-and-push.sh
```

또는 수동으로:

```bash
# ECR 로그인
aws ecr get-login-password --region ap-northeast-2 | \
  docker login --username AWS --password-stdin \
  $(aws sts get-caller-identity --query Account --output text).dkr.ecr.ap-northeast-2.amazonaws.com

# 이미지 빌드
docker build -t site-to-pdf-lambda-worker:latest .

# 이미지 태그
docker tag site-to-pdf-lambda-worker:latest \
  $(aws sts get-caller-identity --query Account --output text).dkr.ecr.ap-northeast-2.amazonaws.com/site-to-pdf-lambda-worker:latest

# ECR에 푸시
docker push \
  $(aws sts get-caller-identity --query Account --output text).dkr.ecr.ap-northeast-2.amazonaws.com/site-to-pdf-lambda-worker:latest
```

### 2. Lambda 함수에 새 이미지 배포

1. Lambda 콘솔 → `site-to-pdf-worker2` 함수 선택
2. **"Code"** 탭 → **"Deploy new image"** 클릭
3. 또는 **"Image"** 섹션에서 **"Deploy new image"** 클릭
4. 최신 이미지 태그 선택 (보통 `latest`)
5. **"Save"** 클릭

### 3. 테스트

1. Lambda 콘솔 → **"Test"** 탭
2. 기존 테스트 이벤트로 실행
3. CloudWatch Logs에서 다음 로그 확인:
   - `[Crawler] Playwright 브라우저 경로: /var/task/.cache/ms-playwright/...`
   - 또는 `[Crawler] 브라우저 경로 자동 감지 실패` (이 경우 추가 조사 필요)

## 예상 결과

성공 시:
- `[Crawler] Playwright 브라우저 경로: /var/task/.cache/ms-playwright/chromium_headless_shell-...`
- 크롤링이 정상적으로 시작됨

실패 시:
- `Executable doesn't exist` 에러가 계속 발생
- 이 경우 Dockerfile에서 브라우저 설치 경로를 다시 확인해야 함
