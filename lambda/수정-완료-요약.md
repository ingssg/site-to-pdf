# Lambda 함수 수정 완료 요약

## 수정 사항

### 1. 브라우저 종료 에러 수정 ✅
- **문제**: 동시에 여러 페이지를 크롤링할 때 브라우저가 닫히는 문제
- **해결**: 동시 크롤링을 순차 처리로 변경하여 브라우저 안정성 향상
- **파일**: `lambda/crawler.js`

### 2. DB 제약조건 에러 수정 ✅
- **문제**: `crawl_completed` 상태가 `status_check` 제약조건에 없음
- **해결**: Supabase에서 제약조건 업데이트 필요
- **SQL 파일**: `lambda/fix-supabase-constraint.sql`

## 배포 완료

✅ Docker 이미지 빌드 완료
✅ ECR에 푸시 완료
✅ Lambda 함수에 새 이미지 배포 완료

## 다음 단계

### Supabase 제약조건 업데이트 (필수!)

Supabase SQL Editor에서 다음 SQL을 실행하세요:

```sql
ALTER TABLE jobs 
DROP CONSTRAINT IF EXISTS status_check;

ALTER TABLE jobs 
ADD CONSTRAINT status_check 
CHECK (status IN (
  'pending', 
  'crawling', 
  'crawl_completed', 
  'page_selected', 
  'summarizing', 
  'generating_pdf', 
  'completed', 
  'failed'
));
```

또는 `lambda/fix-supabase-constraint.sql` 파일의 내용을 복사하여 실행하세요.
