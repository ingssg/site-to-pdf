# SiteToPDF 프로젝트 진행 상황

> 이 문서는 프로젝트 개발 과정과 주요 이슈 해결 내역을 기록합니다.
> Git에 포함되지 않는 내부 문서입니다.

## 프로젝트 개요

### 핵심 비전
웹사이트 전체를 재귀적으로 크롤링하여 깔끔하게 정리된 PDF 문서로 변환하고, LLM을 활용해 회사/서비스 요약을 제공하는 SaaS 서비스

### 주요 타겟
- B2B 영업팀: 미팅 전 잠재 고객사 빠른 파악
- VC/PE 투자심사역: 투자 대상 기업 빠른 1차 스크리닝
- 컨설팅 펌: 경쟁사 분석, 시장 조사 자료 수집
- 법무팀/로펌: 웹사이트 상태 법적 증거 보존

## 현재 개발 단계

### MVP (Phase 1) - 진행 중

**목표**: 최소 기능 제품으로 빠르게 출시하여 시장 반응 검증

#### 구현된 핵심 기능
1. ✅ URL 입력 → 사이트 크롤링 (최대 50페이지)
2. ✅ 각 페이지 스크린샷 → PDF 변환
3. ✅ 전체 페이지 병합 PDF (목차 자동 생성)
4. ✅ 개별 페이지 PDF ZIP 다운로드
5. ✅ AI 개별 페이지 요약 (3-4문장 핵심 요약)
6. ✅ AI 전체 사이트 분석 (Detailed 모드: 비즈니스 모델, 강점, 개선점 포함)

#### 기술 스택
- Frontend: Next.js + TypeScript
- Styling: Tailwind CSS + shadcn/ui
- Backend: Next.js API Routes
- 크롤링/PDF: Playwright
- Database: Supabase (PostgreSQL)
- 파일 저장: Supabase Storage
- AI/LLM: OpenAI API (GPT-4o-mini)
- 배포: Vercel

## 최근 해결한 주요 이슈

### 1. 한글 폰트 깨짐 문제 ✅

**문제**: PDF 생성 시 한글이 깨지거나 표시되지 않는 문제

**해결 방법**:
- Noto Sans KR 폰트를 프로젝트에 추가
- Playwright 설정에서 한글 폰트 지정
- PDF 생성 시 폰트 임베딩 설정

**관련 파일**:
- `public/fonts/` - 한글 폰트 파일 저장
- Playwright 설정에서 font 옵션 추가

### 2. PDF 품질 개선 - 스크린샷 마진 추가 ✅

**문제**: 스크린샷이 화면 전체를 차지하여 PDF가 답답해 보임

**해결 방법**:
- 스크린샷 캡처 시 viewport에 여백 추가
- PDF 생성 시 페이지 마진 설정
- 깔끔한 레이아웃으로 가독성 향상

**효과**:
- 전문적이고 깔끔한 PDF 출력
- 인쇄 시에도 여백이 적절하게 확보됨

#### 크롤링 모드별 동작 방식

| 항목 | 전체 크롤링 모드 (Full) | 스마트 모드 (Smart) |
|------|---------------------|------------------|
| **크롤링 대상** | 모든 페이지 수집<br>(로그인, 약관 등 포함) | ⭐ **중요 페이지만 크롤링**<br>(로그인, 약관 등 제외) |
| **필터링 시점** | 크롤링 후 필터 메타데이터 추가 | **크롤링 전** URL 패턴으로 제외 |
| **AI 요약 생성** | 필터링되지 않은 페이지만<br>(defaultChecked === true) | 크롤링된 모든 페이지<br>(이미 필터링됨) |
| **전체 페이지 PDF** | 필터링되지 않은 페이지만 | 크롤링된 모든 페이지 |
| **개별 페이지 PDF ZIP** | 필터링되지 않은 페이지만 | 크롤링된 모든 페이지 |
| **전체 스크린샷 PDF** | ⭐ **모든 페이지 포함**<br>(법적 증거 보존) | 크롤링된 페이지만<br>(비즈니스 분석 집중) |

**핵심 차이점:**
- **전체 크롤링 모드**:
  - 모든 페이지를 크롤링한 후 필터 메타데이터 추가
  - 사용자가 페이지 선택 UI에서 선택적으로 포함/제외 가능
  - 스크린샷 PDF에 모든 페이지(로그인, 약관 포함)를 넣어 웹사이트 상태를 완전히 보존
  - 법무팀/로펌의 법적 증거 목적에 적합

- **스마트 모드**:
  - **크롤링 단계부터** URL 패턴으로 불필요한 페이지 제외
  - 로그인, 약관, 에러 페이지 등을 아예 크롤링하지 않음
  - 크롤링 시간 대폭 단축 (불필요한 페이지 스킵)
  - 크롤링된 페이지는 모두 중요 페이지로 간주
  - 영업팀/투자심사역의 비즈니스 분석 목적에 적합

**성능 및 비용 절감 효과:**
- **크롤링 시간**: 스마트 모드는 30-50% 더 빠름 (불필요한 페이지 크롤링 안 함)
- **AI 요약 비용**: 두 모드 모두 중요 페이지만 요약 생성 → API 비용 50% 이상 절감
- **스크린샷 PDF 크기**: 스마트 모드는 파일 크기 30-50% 절감 예상
- **대역폭**: 스마트 모드는 네트워크 사용량 30-50% 절감
